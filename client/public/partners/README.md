# Partner Brand Images

This folder is for partner brand logo images.

## Required Images

Please upload the following brand logo images with these exact filenames:

1. **the-telegraph.png** - The Telegraph logo
2. **warner-bros-discovery.png** - Warner Bros. Discovery logo
3. **net-a-porter.png** - Net-A-Porter logo
4. **brandstudio.png** - BrandStudio logo
5. **highsnobiety.png** - Highsnobiety logo

## Image Requirements

- **Format**: PNG (with transparency) or SVG (recommended)
- **Size**: Recommended 200-400px width
- **Aspect Ratio**: Maintain original logo proportions
- **Background**: Transparent background preferred
- **File Size**: Keep under 500KB per image for optimal performance

## Usage

The images will be automatically loaded by the PartnersSection component from this directory.
